# Task Manager Java

## Overview

A console-based task management application built using Java. This project allows users to create, view, update, and delete tasks while storing data using file handling.

## Features

* Add tasks
* View tasks
* Mark tasks as completed
* Delete tasks
* Save tasks across sessions using file storage

## Technologies Used

* Java
* ArrayList
* File Handling
* Git & GitHub

## Concepts Practiced

* Loops and conditional statements
* Collections (ArrayList)
* CRUD operations
* File reading and writing
* Version control using Git

## How to Run

1. Download or clone the repository
2. Open in VS Code or any Java IDE
3. Run `TaskManager.java`
4. Start managing tasks
